# 03 — Screen Specifications

## Landing
Mensagem: aprender com autonomia, sem atalhos.
CTAs: Entrar | Começar agora | Ver como funciona

## Dashboard
Sidebar:
- Início
- Disciplinas
- Dúvidas
- Revisão
- Dicionário
- Cartões de Estudo
- Meu Progresso
- Definições

Hero:
“Olá! Bem-vindo ao EduIA”
“O teu companheiro de aprendizagem com IA para o 5.º ano em Portugal.”

Ações rápidas:
- Fazer uma pergunta
- Enviar para revisão
- Criar cartões

Cards de disciplinas vindos de `subjects.json`.

## Disciplina
Nome, ícone, temas mockados inicialmente.
Ações: dúvida, prática, cartões, revisão.

## Tutor
Histórico, input, enviar, botões:
- Preciso de uma pista
- Explica de outra forma
- Quero tentar sozinho

## Revisão
Drag/drop, escolher imagem, preview, analisar, abrir Tutor.

## Dicionário
Campo de palavra, significado, exemplos, sinónimo/antónimo, criação de frase.

## Cartões
Disciplina, tema, 3/5/10, um cartão de cada vez, pista antes da explicação.

## Progresso
Temas, sessões, exercícios, autonomia, necessidade de pistas.
