# 02 — User Flow

## Entrada
Landing/Login → Perfil de teste → Início

## Início
Início → Disciplinas | Dúvidas | Revisão | Dicionário | Cartões | Progresso

## Disciplinas
Escolher disciplina → escolher tema → Tirar dúvida | Praticar | Criar cartões | Rever matéria

## Dúvidas / TPC
Escolher contexto → escrever dúvida → EduIA valida → pista mínima → aguarda → adapta → prática → resumo

## Revisão
Upload → preview → confirmar → análise → ponto a rever → Tutor Socrático → nova tentativa → resumo

## Dicionário
Palavra → significado → exemplo → sinónimo/antónimo → criança cria frase → feedback

## Cartões
Disciplina → tema → cartões → criança responde → pista → explicação → próximo → resumo

## Tentativa de resposta pronta
“Diz só a resposta.”
→ recusa positiva
→ “Posso ajudar-te a chegar lá.”
→ pista mínima

## Conteúdo sensível/não educativo
Resposta curta e segura → redirecionar → quando necessário incentivar conversa com adulto de confiança.
