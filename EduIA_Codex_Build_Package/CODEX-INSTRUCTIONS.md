# CODEX-INSTRUCTIONS

## Missão
Construir a V0 da EduIA Web App usando este pacote como fonte de verdade.

## Antes de codificar
1. Ler todos os ficheiros.
2. Resumir o escopo.
3. Propor arquitetura mínima.
4. Listar ambiguidades.
5. Apresentar plano alinhado a `TASKS.md`.
6. Não escrever código até aprovação.

## Princípios
- não inventar funcionalidades;
- PT-PT na interface;
- código interno pode estar em inglês;
- mocks antes de integrações reais;
- segurança infantil e privacidade são requisitos centrais;
- acessibilidade e responsividade desde o início;
- disciplinas vêm de `data/subjects.json`;
- não expor API keys.

## Experiência central
`disciplina → dúvida → orientação socrática → prática → resumo`

## Primeiro pedido recomendado
“Lê o pacote completo, sem escrever código. Resume o escopo, propõe a arquitetura mínima da V0, lista ambiguidades e apresenta plano por milestones.”

## Depois da aprovação
“Implementa apenas Milestone 0 e 1. Não uses IA real. Usa mocks/adapters. No final executa lint, typecheck e testes.”
