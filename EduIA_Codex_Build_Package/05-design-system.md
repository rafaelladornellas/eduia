# 05 — Design System

## Direção
Amigável, limpa, tranquila, educativa sem parecer infantil demais.

## Cores iniciais
- Navy #0E2A55
- Teal #18B9B7
- Cyan #3FC4D6
- Background #F7FBFC
- Text #12243C
- Success #3BAE7A
- Warning #F2A23A

## Componentes
Sidebar, Topbar, SubjectCard, QuickActionCard, TutorBubble, HintButton, UploadCard, DictionaryResult, StudyCard, ProgressCard, SafetyNotice.

## Acessibilidade
- WCAG AA
- foco visível
- teclado
- labels
- alt text
- touch target ~44px
- inputs >=16px no mobile
- não usar só cor para comunicar

## Responsividade
Desktop: sidebar
Tablet: sidebar compacta/top nav
Mobile: navegação simples
